# Linux Gateway

Camada Linux do RadioNode BR.

Plataformas iniciais:
- Raspberry Pi 3B+;
- DigiPi;
- Raspberry Pi OS/Debian compatível.

Responsabilidades previstas:
- serviço/agent de comunicação com ESP32;
- Direwolf e APRS-IS;
- SvxLink/EchoLink;
- logs e observabilidade;
- dashboard;
- adaptadores de rede.

DigiPi é suportado como plataforma, mas não é uma dependência arquitetural obrigatória.
