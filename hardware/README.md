# Hardware

Área de hardware do RadioNode BR.

Estrutura prevista:
- `schematic/` — esquemáticos;
- `pcb/` — layouts da futura placa;
- `bom/` — lista de materiais;
- `enclosure/` — gabinete e montagem mecânica.

Protótipo V0.1 de referência:
- ESP32-S3 N16R8;
- SX1278 LoRa 433 MHz;
- NEO-6M GPS;
- ST7789 240x240 planejado;
- Raspberry Pi 3B+ como gateway Linux inicial.

A PCB própria só será iniciada após validação das interfaces críticas em módulos de bancada.
